Tech Skills 101

I have taught several OLLI courses on digital technology. The primary aim of each of those courses was to help increase people's digital literacy (and so covered roughly the same set of topics). Each subsequent time I taught the course, I refined the syllabus and content based on student feedback from the previous course. This subsection contains the latest version of the course outline.

We drew from this outline for a number of meetings in the first half of 2026. In fact, in July we started repeating the course content from the beginning at group member's request.
